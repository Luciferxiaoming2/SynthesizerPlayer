# 环境准备与模型下载

本文档说明从云端仓库 `git clone` 后，还需要准备哪些本地环境、模型和工具文件。仓库只保存业务代码、测试和文档；大模型、运行时、音频文件和打包产物不提交。

## 1. 克隆仓库

```powershell
git clone https://github.com/Luciferxiaoming2/SynthesizerPlayer.git D:\project\code\audio_forge
cd D:\project\code\audio_forge
```

如果已经克隆过：

```powershell
cd D:\project\code\audio_forge
git pull
```

## 2. 开发 Python 环境

项目当前开发环境约定为：

```text
D:\uv\venvs\audio_forge
```

创建环境：

```powershell
uv venv D:\uv\venvs\audio_forge --python 3.11
```

安装基础开发依赖：

```powershell
uv pip install --python D:\uv\venvs\audio_forge\Scripts\python.exe -e ".[dev,dsp,package,asr,f0]"
```

安装真实人声分离依赖：

```powershell
uv pip install --python D:\uv\venvs\audio_forge\Scripts\python.exe demucs
```

验证：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m pytest tests\test_ui_workbench.py -q
```

启动开发版 UI：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m ui.main_window
```

放置目录：

```text

```

目录内至少需要：

```text
ffmpeg.exe

```

如果已经有下载好的 ffmpeg，可以直接复制到该目录。

## 5. rubberband

放置目录：

```text
plugins\models\rubberband
```

目录内至少需要：

```text
rubberband.exe
```

跑调/变调功能会优先使用该工具。

## 6. faster-whisper 歌词识别模型

推荐先准备 `small` 模型，体积和效果比较均衡。下载命令：

```powershell
cd D:\project\code\audio_forge
D:\uv\venvs\audio_forge\Scripts\python.exe -c "from huggingface_hub import snapshot_download; from pathlib import Path; print(snapshot_download(repo_id='Systran/faster-whisper-small', local_dir=str(Path('plugins/models/faster-whisper/small').resolve())))"
```

低配或轻量包可使用 `base`：

```powershell
cd D:\project\code\audio_forge
D:\uv\venvs\audio_forge\Scripts\python.exe -c "from huggingface_hub import snapshot_download; from pathlib import Path; print(snapshot_download(repo_id='Systran/faster-whisper-base', local_dir=str(Path('plugins/models/faster-whisper/base').resolve())))"
```

应用优先使用：

```text
plugins\models\faster-whisper\small
```

如果不存在，会回退到：

```text
plugins\models\faster-whisper\base
```

## 7. Demucs 模型缓存

真实人声分离依赖 Demucs 和 PyTorch。开发环境安装好 `demucs` 后，首次真实分离会自动下载模型缓存。

为了交付便携版，建议把 Demucs/PyTorch 缓存放到：

```text
plugins\models\torch
```

开发测试时可显式指定：

```powershell
$env:TORCH_HOME='D:\project\code\audio_forge\plugins\models\torch'
```

然后运行一次真实分离导入，让模型缓存落到该目录。

## 8. ACE-Step 改词唱运行时

ACE-Step 运行时放置目录：

```text
plugins\runtime\ACE-Step-1.5
```

要求该目录内至少存在：

```text
pyproject.toml
acestep\
.venv\Scripts\acestep-api.exe
```

开发时可以在该目录中启动：

```powershell
cd D:\project\code\audio_forge\plugins\runtime\ACE-Step-1.5
uv run acestep
```

应用内“启动 ACE 模型”会优先尝试启动：

```text
plugins\runtime\ACE-Step-1.5\.venv\Scripts\acestep-api.exe
```

如果找不到，才会回退到系统 `uv run --no-sync acestep-api`。

## 9. 生产环境

生产环境用于便携版或安装包，不应和开发环境混用。

默认路径：

```text
release\AudioForgePortable_next\plugins\models\python
```

创建命令：

```powershell
cd D:\project\code\audio_forge
powershell.exe -ExecutionPolicy Bypass -File scripts\packaging\create_production_env.ps1
```

便携版通过以下文件指向生产 Python：

```text
release\AudioForgePortable_next\demucs_python.txt
```

开发调试版可以指向本机开发环境：

```text
release\AudioForgePortable_dev\demucs_python.txt
```

内容为：

```text
D:\uv\venvs\audio_forge\Scripts\python.exe
```

## 10. 打包命令

构建 UI：

```powershell
cd D:\project\code\audio_forge
powershell.exe -ExecutionPolicy Bypass -File scripts\packaging\build_windows_ui.ps1
```

输出：

```text
dist\audio-forge-ui
```

复制到开发便携版：

```powershell
Copy-Item -Path dist\audio-forge-ui\* -Destination release\AudioForgePortable_dev -Recurse -Force
```

生成完整安装包需要先安装 Inno Setup，然后执行：

```powershell
powershell.exe -ExecutionPolicy Bypass -File scripts\packaging\build_full_installer.ps1
```

输出：

```text
release\AudioForge_Full_Setup.exe
```

## 11. 交付建议

不建议默认交付完整离线包。完整离线包会超过 20GB，且客户电脑配置要求较高。

推荐交付方式：

1. 轻量客户端：主程序、基础音频工具、基础歌词和跑调功能。
2. 插件包：人声分离、高清歌词识别、ACE-Step 改词唱分别拆包。
3. 后端服务：把 ACE-Step、Demucs、百炼或其它云端 API 放到服务器侧。
