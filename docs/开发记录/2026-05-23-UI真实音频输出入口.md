# 2026-05-23 UI 真实音频输出入口

## 本次目标

在 UI 工作台中接入真实声卡输出入口，同时保持默认预览播放不占用音频设备，避免开发测试和普通用户误触发声。

## 已完成

- 扩展 `core_engine/player/sounddevice_output.py`：
  - 新增 `close()`，允许 UI 停止输出流但不强制重置播放位置。
- 扩展 `ui/main_window.py`：
  - `WorkbenchBridge` 新增 `audioOutputActive`。
  - 新增 `startAudioOutput()` 和 `stopAudioOutput()`。
  - 播放预览 timer 在真实音频输出激活时只刷新 UI 状态，不重复消费音频 buffer。
- 扩展 `ui/qml/SingleScreenUI.qml`：
  - 新增 `Audio / Audio Off` 按钮。
  - `Play` 仍作为安全的预览推进入口。

## 本机验证

- 播放引擎和 UI bridge 针对测试通过。
- QML offscreen 加载成功，无 binding warning。

## 对旧源代码迁移状态的影响

- 双轨播放同步的业务语义已完成第一版迁移。
- 新实现不沿用旧项目的 pyglet/VLC 播放方式，而是使用 `DualTrackPlaybackEngine` 与可选 `SoundDeviceOutput`。

## 当前边界

- 没有自动探测或选择声卡设备。
- 没有在自动测试中打开真实声卡。
- 真实播放体验还需要人工试听验证。
