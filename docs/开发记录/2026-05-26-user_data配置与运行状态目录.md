# 2026-05-26 user_data 配置与运行状态目录

## 背景

便携版升级时需要区分程序文件、歌曲工程、模型文件和用户运行状态。此前歌曲工程已统一进入 `save/`，但主题、音量、播放模式、日志等配置还没有独立落点。

## 修改

- 新增 `user_data/` 作为用户运行数据目录。
- 自动创建：
  - `user_data/config.json`：播放模式、歌曲库目录、人声/伴奏音量、跑调程度、歌词偏移、ACE 基础地址。
  - `user_data/recent.json`：当前歌曲等最近状态。
  - `user_data/logs/`：应用状态日志。
  - `user_data/cache/`：后续可清理缓存。
- `save/` 继续只用于导入歌曲、分离结果、歌词、改词版本等歌曲工程内容。
- `.gitignore` 新增 `user_data/`，避免本地配置、日志和运行缓存进入仓库。

## 验收

- 启动应用会自动创建 `user_data/config.json`、`user_data/logs/`、`user_data/cache/`。
- 播放模式、音量、跑调程度、歌词偏移会写入配置，并在下次启动时恢复。
- 应用状态消息会追加到 `user_data/logs/app.log`。
