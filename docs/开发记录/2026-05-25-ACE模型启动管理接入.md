# 2026-05-25 ACE 模型启动管理接入

## 方案判断

用户提出的方案可行：由桌面应用统一启动 ACE 模型、释放端口、显示启动进度，并在模型 API 就绪后更新状态。结合 PyQt 桌面应用特性，本次采用 Qt 官方推荐的 `QProcess` 管理外部长进程，避免主界面阻塞。

## 本次改造

- 右侧“AI 智能改唱工作舱”新增“启动 ACE 模型”和“停止模型”按钮。
- 启动前检测 `7860` 端口，如被占用则自动查找监听进程并执行 `taskkill /F /T` 释放端口。
- 使用 `QProcess` 启动：
  - `uv run acestep --enable-api --server-name 127.0.0.1 --port 7860`
- 读取 ACE stdout 日志并映射为中文进度：
  - 端口检查
  - 硬件检测
  - CPU 模式
  - 创建 Gradio 工作台
  - 启动本地服务
  - API endpoints enabled
- API 就绪后显示“ACE 模型已启动，自动改词接口可用”。

## 注意

- 当前自动释放端口只处理 `7860` 的 LISTENING 进程，避免误杀其它无关任务。
- 如果用户手动启动了 ACE，应用也会通过 `/health` 与 `/config` 检测状态。
- CPU 模式启动和推理耗时较长，进度条只表示启动阶段，不代表生成任务进度。
