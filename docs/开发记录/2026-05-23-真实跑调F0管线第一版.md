# 2026-05-23 真实跑调 F0 管线第一版

## 背景

根据当前优先级，先攻克三个难点中相对可控的“真实跑调”。目标不是马上达到最终 PyWorld 声码器质量，而是先把可测试、可评估、可替换的 F0 管线搭起来。

## 本批完成内容

### 1. F0 估计

在 `core_engine/dsp/tone_deaf.py` 中新增：

- `F0Track`
- `estimate_f0_track`
- `estimate_frame_f0`

实现方式：

- 使用 numpy 自相关估计每帧基频。
- 默认 F0 范围为 70Hz - 900Hz。
- 输出每帧时间、频率、置信度。

### 2. 跑调漂移曲线

新增：

- `DriftCurve`
- `generate_drift_curve`
- `drift_cents_at`
- `smooth_curve`

实现方式：

- 基于 F0 置信度生成低频随机游走。
- 使用 cents 表示音高偏移。
- 使用平滑窗口减少机械抖动。
- 漂移幅度受 `drift_ratio` 控制。

### 3. 跑调渲染升级

`render_tone_deaf_vocal` 现在不再直接用简单 chunk index 随机值，而是：

1. 估计原始人声 F0。
2. 生成 F0 漂移曲线。
3. 按播放时间查询 drift cents。
4. 对局部分块做时长保持的重采样漂移。

说明：这仍是轻量 fallback，不是最终 PyWorld 声码器版；但接口已经适合后续替换真实 PyWorld 后端。

### 4. F0 评估增强

更新 `harness/eval_harness/f0_drift_eval.py`：

- 输出 `normalized_difference`
- 输出 `original_voiced_ratio`
- 输出 `processed_voiced_ratio`
- 输出 `median_f0_shift_cents`

新增 `harness/cli_harness/analyze_f0_drift.py`，可以对原始人声和处理后人声做 F0 指标分析。

## 当前局限

- 目前不是高质量声码器重建，音质不等同 PyWorld。
- 局部分块重采样会改变音色细节，后续需要用 PyWorld 的 F0/SP/AP 重建替换。
- 当前 F0 估计器适合 smoke 与简单音频，对复杂歌声仍需更强算法。

## 下一步建议

- 接入 PyWorld 可选后端：如果环境安装成功，则用 PyWorld；否则保留 numpy fallback。
- 将跑调结果接入播放 buffer 热替换流程。
- 增加分块离线渲染缓存，避免 UI slider 每次拖动都实时重算整轨。
