# 2026-05-24 右栏功能面板第一批

## 背景

右栏参考图中的 F0、DSP、分离预设和系统状态面板，之前主要承担视觉展示，存在采样率、延迟、ASIO 等静态假数据。用户希望逐步实现右栏功能，因此本批先把已具备后端能力的部分接成真实状态和可操作入口。

## 本次推进

- 新增右栏推进计划到总进度文档，拆分为三批推进。
- F0 面板显示真实播放采样率和跑调状态：
  - 未加载歌曲时提示先导入或加载。
  - 根据跑调强度显示原声、轻微跑调、明显跑调或强跑调状态。
- “分离与重组算法预设”接入真实切换：
  - 标准人声：切换为快速预览分离。
  - 极致消除：切换为 Demucs 人声分离。
  - 该设置影响下一次导入歌曲。
- 右栏底部改为真实状态：
  - 输出引擎：播放中、已就绪、未检测到设备。
  - 对齐检测：显示上一次检测延迟，未检测时显示“未检测”。
  - VST 状态：显示未加载或当前插件文件名。
  - 歌词引擎：显示当前中文歌词后端名称。
- “AI 自动修补原唱”继续置灰，并改为明确说明暂未接入真实模型，避免误导用户。
