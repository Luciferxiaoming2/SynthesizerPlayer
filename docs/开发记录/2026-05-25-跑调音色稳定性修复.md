# 2026-05-25 跑调音色稳定性修复

## 背景

用户反馈跑调时部分句子或单字音色会变化，听感像某些字突然换了质感。

## 处理

- 保留 Rubber Band 的 `--formant`，用于尽量保持人声共振峰和原音色。
- 去掉 `--centre-focus`，避免 stereo 中置聚焦处理额外改变声像和单声道质感。
- 将跑调 pitchmap 从短帧密集变化改为稀疏、慢变化的句级曲线：
  - 禁用快速 wobble 写入 Rubber Band pitchmap。
  - 降低动态漂移幅度。
  - 拉长过渡窗口。
  - pitchmap 点最短间隔约 260ms，避免按字跳变。

## 当前结论

这是目前跑调音色稳定性的更优方案：跑调仍由整体音高偏移和慢速句级漂移产生，不再用高频率逐字/逐帧变调去制造效果。后续如果继续追求更自然，可考虑直接接 Rubber Band API 或专门的实时音高校正/偏移库，获得更细的 formant 和动态 pitch 控制。
