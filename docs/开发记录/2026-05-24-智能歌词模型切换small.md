# 2026-05-24 智能歌词模型切换 small

## 背景

用户反馈 base 模型歌词识别准确率不足，需要换成更合适的模型。综合准确率、包体积、CPU 速度和普通用户双击运行体验，本次将默认智能歌词模型切换为 `Systran/faster-whisper-small`。

## 本次推进

- `FasterWhisperConfig` 默认模型从 `base` 改为 `small`。
- UI 后端查找模型顺序改为：
  1. `plugins/models/faster-whisper/small`
  2. `plugins/models/faster-whisper/base`
  3. PyInstaller `_internal` 中的 small/base 随包目录
- PyInstaller spec 会自动收集 `small` 和 `base` 两个本地模型目录，哪个存在带哪个。
- README 更新交付说明：优先放置 small，缺少 small 时回退 base。
- 新增测试覆盖 small 优先、base 回退。

## 需要执行的下载命令

```powershell
cd D:\project\code\audio_forge
D:\uv\venvs\audio_forge\Scripts\python.exe -c "from huggingface_hub import snapshot_download; from pathlib import Path; print(snapshot_download(repo_id='Systran/faster-whisper-small', local_dir=str(Path('plugins/models/faster-whisper/small').resolve())))"
```

## 后续

- 下载完成后重新打包，便携版会包含 small 模型。
- 如果用户机器较慢，可保留 base 目录作为低配回退。
