# 2026-05-23 跑调缓存与播放 Buffer 替换

## 本批目标

推进 M6：跑调缓存与播放 buffer 替换。

## 完成内容

- `StereoTrackBuffer` 新增：
  - `with_vocal`
  - `with_instrumental`
- `DualTrackPlaybackEngine` 新增：
  - `replace_buffers`
  - 可在保留播放位置的情况下切换底层双轨 buffer。
- 新增 `core_engine/dsp/tone_deaf_cache.py`：
  - `ToneDeafRenderKey`
  - `ToneDeafBufferCache`
  - 按 ratio、seed、frame_count、sample_rate 缓存跑调人声。
- 新增 `harness/cli_harness/render_tone_deaf_mix.py`：
  - 读取 vocal/instrumental。
  - 渲染跑调 vocal。
  - 和伴奏混合导出 wav。

## 可运行看效果

先生成 mock 音频：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.generate_mock_audio --output-dir harness\mock_data
```

导出普通混音：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.run_dual_mix --vocal harness\mock_data\vocal.wav --instrumental harness\mock_data\instrumental.wav --output harness\mock_data\mix.wav
```

导出跑调混音：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.render_tone_deaf_mix --vocal harness\mock_data\vocal.wav --instrumental harness\mock_data\instrumental.wav --output harness\mock_data\tone_deaf_mix.wav --ratio 0.4
```

然后可以直接播放：

- `harness/mock_data/mix.wav`
- `harness/mock_data/tone_deaf_mix.wav`
