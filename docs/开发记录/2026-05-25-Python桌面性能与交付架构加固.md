# 2026-05-25 Python 桌面性能与交付架构加固

## 背景

本项目是 Python + PyQt6/QML 桌面应用，核心风险包括 GUI 主线程卡死、音频大数组占用内存、AI 模型重复加载、高分屏显示不稳定、PyInstaller 打包体积膨胀等。

## 本次推进

- 在进度文档中新增“Python 桌面性能与交付架构加固”专项，并用清单跟踪完成情况。
- 启动入口增加 Qt HiDPI 环境变量：
  - `QT_ENABLE_HIGHDPI_SCALING=1`
  - `QT_SCALE_FACTOR_ROUNDING_POLICY=PassThrough`
- 导出音频从同步执行改为 `QThread` 后台任务，避免导出期间 UI 卡死。
- 切歌、删除歌曲、清空列表和清空当前歌曲状态时，清理跑调缓存并触发 `gc.collect()`。
- `FasterWhisperLyricsTranscriber` 增加进程内模型缓存，同配置模型只创建一次，减少重复加载和内存抖动。

## 仍需后续处理

- 继续瘦身 PyInstaller 的 Qt/QML 插件收集范围，减少无用 QtQuick3D 等内容。
- 建立统一模型管理器，集中管理 ASR、改词唱模型和外部模型的预加载、关闭、状态提示。
