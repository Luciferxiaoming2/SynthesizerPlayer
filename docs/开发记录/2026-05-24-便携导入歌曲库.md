# 2026-05-24 便携导入歌曲库

## 背景

用户反馈每次打开应用都像要重新导入歌曲，原因是导入工程目录和默认扫描目录不一致。便携版应在启动脚本/程序同级目录放一个固定歌曲库目录，导入后的歌曲工程都进入这里。

## 本次推进

- 默认导入工程目录改为程序根目录下的 `导入歌曲`。
- 默认歌曲扫描目录也指向 `导入歌曲`。
- 应用启动桥接层时会自动创建 `导入歌曲` 目录。
- `.gitignore` 增加 `导入歌曲/`，避免用户导入音频和工程进入源码仓库。
- 左侧歌曲库新增直接可见的：
  - `删除选中`
  - `清空列表`

## 验证

- 新增测试确认默认歌曲库为 `导入歌曲`，且目录会自动创建。
- 导入完整歌曲后，工程路径会落在 `导入歌曲` 下。

## 说明

- `清空列表` 只清空当前界面列表，不删除磁盘文件。
- `删除选中` 当前也是从列表移除，不删除磁盘文件；如果需要真正删除导入工程目录，后续应加二次确认弹窗。
