# 2026-05-25 save 歌曲删除与改词状态清理

## 背景

用户期望左侧“删除选中”和“清空列表”不仅移除界面列表，还要删除 `save` 文件夹中对应的歌曲工程或普通音频文件，并同步清理右栏 AI 智能改唱工作舱中的选中句、输入内容和已生成试听版本。

## 修改

- `deleteSongAt` 现在会删除当前歌曲库目录内对应的工程文件夹或普通音频文件。
- `clearSongList` 现在会遍历当前歌曲列表并删除对应磁盘项目。
- 删除操作带有安全边界，只允许删除当前歌曲库目录内的路径。
- 删除当前歌曲或清空列表后，会清理播放状态、歌词时间轴、AI 改词唱试听版本和右栏选中态。
- QML 在点击“删除选中”或“清空列表”时会立即清空右栏改词输入和选中行。
- 删除选中或清空列表前会弹出二次确认，只有用户点击“确认删除”才真正删除磁盘文件。

## 验证

- 新增删除工程文件夹并加载下一首的测试。
- 新增删除最后一首时清理 AI 改词唱状态的测试。
- 新增清空列表时删除普通音频及同名歌词文件的测试。
