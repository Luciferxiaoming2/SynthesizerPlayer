# 2026-05-24 歌词框与播放模式

## 背景

用户反馈当前滚动歌词高亮背景框过大，视觉上像横幅；底部循环按钮虽然存在，但循环播放和列表播放没有真实生效。

## 本次推进

- 当前歌词高亮框改为按歌词内容自适应宽度，减少空白背景。
- 已唱过歌词保持缩小和弱化，不抢当前句视觉焦点。
- 底部播放模式按钮接入真实逻辑：
  - `列表播放`：当前歌曲播放结束后自动进入下一首，列表末尾回到第一首。
  - `单曲循环`：当前歌曲播放结束后自动从头播放。
- 左侧歌曲列表会跟随后端当前歌曲索引同步，自动切歌后高亮更新。

## 验证

- 新增 `WorkbenchBridge` 测试覆盖单曲循环和列表自动切歌。
- QML smoke 用于验证界面属性绑定可加载。

## 后续

- 如果需要“随机播放/播完停止”，可在当前播放模式基础上继续扩展。
