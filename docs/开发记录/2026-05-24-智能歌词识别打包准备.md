# 2026-05-24 智能歌词识别打包准备

## 背景

用户指出普通用户不应该理解或手动安装 `fast-whisper/faster-whisper`。界面和交付包应只表达“智能识别歌词”，底层依赖由应用内置。

## 本次推进

- 开发环境已安装智能歌词识别依赖：
  - `faster-whisper`
  - `ctranslate2`
  - `av`
  - `tokenizers`
  - `onnxruntime`
  - `huggingface-hub`
- PyInstaller spec 已改为自动收集这些识别依赖；如果环境安装了 ASR 依赖，打包时会随包带上。
- UI 文案改为“智能识别歌词”，不再提示用户安装底层 Python 包。
- 识别模型目录约定为：
  - `plugins/models/faster-whisper/base`
- 应用启动后会优先使用随包模型目录；如果模型缺失，会提示“请使用完整安装包/联系交付人员补齐模型包”。
- README 已更新，说明模型由交付人员放入目录后再打包。

## 当前阻塞

模型下载需要访问 Hugging Face。当前沙盒联网权限被自动审核服务拦截，无法由 Codex 直接下载模型文件。

可在本机有网络权限时执行：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -c "from huggingface_hub import snapshot_download; from pathlib import Path; print(snapshot_download(repo_id='Systran/faster-whisper-base', local_dir=str(Path('plugins/models/faster-whisper/base').resolve())))"
```

执行成功后重新打包，便携版会自动包含模型文件。

## 后续

- 模型到位后，需要运行一次真实识别 smoke：导入歌曲，选择“智能识别歌词”，点击“生成歌词”。
- 若包体过大，可改用 `Systran/faster-whisper-small` 或 `tiny` 模型做低配版。
