# 2026-05-23 Windows 命令行打包准备

## 本次目标

围绕“普通用户无需安装 Python 环境”的最终交付目标，先准备一个可冻结的命令行 MVP。图形界面还未正式开发，因此本阶段不打 GUI 包，先把核心音频能力的可分发入口打通。

## 已完成

- 新增 `scripts/packaging/audio_forge_cli.py`：
  - 作为 PyInstaller 友好的统一命令分发器。
  - 覆盖 `generate-mock`、`run-pitch`、`analyze-f0`、`run-tone-deaf-mix`、`run-effects`、`export-mix`、`run-lyric`。
- 新增 `scripts/packaging/audio_forge_cli.spec`：
  - 定义 `audio-forge-cli.exe` 打包目标。
  - 暂时排除 PyQt6、librosa、pyworld，降低命令行基础包体和依赖风险。
- 新增 `scripts/packaging/build_windows.ps1`：
  - 使用当前 uv 虚拟环境中的 Python 执行 PyInstaller。
  - 支持 `-InstallPackagingDeps` 自动安装 package extra。
- 更新 `pyproject.toml`：
  - 新增 `package` optional dependency，包含 `pyinstaller`。
- 更新 `Makefile`：
  - 新增 `install-package` 和 `package-cli`。
- 新增 `docs/runbooks/packaging_windows.md`：
  - 记录打包命令、输出路径和打包后自测流程。

## 当前边界

- 这一版打包的是命令行 MVP，不是最终 PyQt6/QML 应用。
- VST 插件、AI 模型权重、旧歌曲资源不会默认打进包。
- 真实改词唱后端仍作为外部实验能力接入。

## 本机验证

- 已安装 `pyinstaller` 到 `D:\uv\venvs\audio_forge`。
- 已成功生成 `dist/audio-forge-cli/audio-forge-cli.exe`。
- 打包后的 exe 已通过以下最小自测：
  - `run-lyric` 生成 `dist/audio-forge-cli/mock_data/rewrite_preview.wav`。
  - `generate-mock` 生成 vocal/instrumental mock wav。
  - `export-mix` 生成 `dist/audio-forge-cli/mock_data/export_mix.wav`。
