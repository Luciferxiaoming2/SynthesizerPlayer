# 2026-05-23 普通音乐文件夹扫描与导入刷新

## 背景

用户反馈导入歌曲成功后左侧歌曲列表没有显示，选择 `D:\music` 文件夹扫描结果为 0，滚动歌词区域也没有显示歌词。

## 根因

- 旧的歌曲库扫描只识别已经拆分好的工程目录，即目录里必须包含人声和伴奏文件。
- 普通音乐文件夹通常是 `mp3/m4a/flac/ogg/aac/wav` 单文件列表，因此会被扫描逻辑跳过。
- 导入完成后只更新了当前播放路径，没有把新工程插入左侧 `songNames` 模型。

## 本次调整

- `scan_song_library` 同时支持普通音频文件和已拆分工程目录。
- 普通音频文件会显示在左侧歌曲库；点击“加载选中”时自动进入导入流程。
- 导入成功后自动把新工程插到左侧歌曲库第一项，并刷新 QML 模型。
- preview 歌词占位文案改为中文，避免没有真实歌词时看起来像空白。
- 扫描和导入状态改为中文提示。

## 本机验证

- `D:\music` 可扫描到 27 首普通音乐文件。
- `D:\music\多远都要在一起.m4a` 可导入成功，并自动加入左侧歌曲库。
- 导入后 `lyricLines` 可返回中文占位歌词；有同名 `.lrc/.srt` 时会使用真实歌词。

## 后续

- 可引入 `mutagen` 或 `tinytag` 读取标题、歌手、专辑、时长等元数据，优化左侧列表展示。
- 格式兼容继续以项目本地 ffmpeg 为主，保持对 MP3/M4A/AAC/FLAC/OGG/WAV 的统一转码入口。
