# 2026-05-23 单曲导入工程入口第一版

## 本次目标

响应客户“导入一首完整歌曲后自动拆出人声、伴奏和歌词”的需求，先完成工程入口第一版：创建歌曲工程目录、生成双轨 stem、匹配歌词，并接入 CLI 与 UI。

## 已完成

- 扩展 `core_engine/player/stem_separator.py`：
  - 新增 `PreviewStemSeparator`，作为轻量占位分离后端。
  - 新增 `DemucsStemSeparator`，默认 CPU 模式调用 `python -m demucs`。
  - 新增 `ExternalCommandStemSeparator`，支持后续接 Demucs/Spleeter/UVR5 命令行。
- 新增 `core_engine/importer/song_importer.py`：
  - 创建唯一工程目录。
  - 复制原始歌曲。
  - 调用分离后端生成 `stems/vocal.wav` 和 `stems/instrumental.wav`。
  - 优先复制同名 `.lrc` / `.srt` 到工程目录。
  - 写入 `project.json` manifest。
- 新增 `harness/cli_harness/import_song.py`：
  - 支持 `preview` 和 `external` 两种分离后端。
- 扩展 `ui/main_window.py` 和 `ui/qml/SingleScreenUI.qml`：
  - 新增 `Import Song` 入口。
  - 导入后自动填充 vocal、instrumental、lyrics/output 路径并加载播放。
- 扩展打包 CLI：
  - `audio-forge-cli import-song` 可用。

## 本机验证

- `tests/test_song_importer.py` 通过。
- UI bridge 导入完整歌曲测试通过。
- `python -m harness.cli_harness.import_song --input ...` 可生成工程目录和双轨 stem。

## 当前边界

- `PreviewStemSeparator` 不是真实人声分离，只用于跑通导入工程链路。
- 真实分离已具备 Demucs 命令适配器，但当前环境尚未安装和下载 Demucs 模型。
- 没有歌词时 ASR 自动转写还未实现。
