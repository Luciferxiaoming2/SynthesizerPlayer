# 2026-05-25 改词唱杂音与静音修复

## 背景

用户反馈播放到改词唱修改句时没有正常声音，并伴随类似“咕咕咕”的杂音。排查后确认本机轻量改词唱存在两个风险点：

- Windows SAPI 语音合成脚本使用 `$args` 传参，在打包/子进程环境中可能取不到歌词或输出路径，失败后落到测试用的正弦波预览音。
- 生成语音片段与原歌词句子时长不一致时，旧逻辑会直接截断或补静音，导致一句话后半段没声。

## 修改

- 本机轻量改词唱改为显式 PowerShell `param($lyric, $outPath, $target)` 传参，避免歌词和输出路径丢失。
- 按歌词内容自动选择中文或英文系统语音，降低语言不匹配导致的含混读音。
- 默认不再把 SAPI 失败兜底为正弦波测试音；失败时直接提示本机语音合成不可用，避免把怪声写进歌曲。
- 改词唱替换片段会按目标歌词行时长做重采样适配，避免生成语音太短时后半句静音。

## 验证

- 本机 SAPI 探针可稳定生成有效 wav。
- `tests/test_ai_singer_workflow.py` 与 `tests/test_ui_workbench.py` 通过。
