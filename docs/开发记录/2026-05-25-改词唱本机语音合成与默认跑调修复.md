# 2026-05-25 改词唱本机语音合成与默认跑调修复

## 问题

用户在便携版中使用改词唱时，当前歌曲工程的人声音轨实际存在，但本机轻量改词唱生成失败。复现后发现 Windows SAPI 语音合成只生成了 46 字节空 wav，导致改词唱无法替换片段。

同时，应用启动后的跑调程度默认值仍为 40%，不符合“初始跑调为 0”的预期。

## 修复

- `LocalSpeechSingingClient` 改用临时 `.ps1` 脚本执行 Windows SAPI，避免 `powershell -Command` 参数没有正确传入导致空输出。
- 本机轻量改词唱默认增加 `PreviewSingingClient` 兜底，防止系统语音组件不可用时直接失败。
- `WorkbenchBridge` 默认跑调程度从 `0.4` 改为 `0.0`。
- QML `tonePreviewValue` 和隐藏同步滑条默认值从 `0.4` 改为 `0.0`。
- 更新右栏状态测试：默认加载歌曲后显示“原声稳定”。

## 验证

- 已用当前便携版 `save/离开我的依赖` 工程验证，无需重新导入即可生成改词唱试听 wav。
- `D:\uv\venvs\audio_forge\Scripts\python.exe -m pytest tests/test_ai_singer_workflow.py tests/test_ui_workbench.py -q`
- 结果：`67 passed`
