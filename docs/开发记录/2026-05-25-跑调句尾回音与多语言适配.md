# 2026-05-25 跑调句尾回音与多语言适配

## 背景

用户反馈部分歌曲一句唱完后仍能听到一点原唱回音。该问题通常不是歌词语言造成的，而是人声分离后伴奏轨里残留了原唱尾音或混响尾巴；当主唱人声已经被跑调处理后，伴奏里的未跑调尾音会更明显。

## 本次推进

- 在伴奏残留人声抑制中增加短释放尾音处理：
  - 当检测到人声频段活动后，后续约 360ms 内继续对 vocal band 做轻量衰减。
  - 该处理基于音频频谱和能量，不依赖歌词文字，因此适用于中文、英文、日文、韩文、俄文、阿拉伯文等不同语言歌曲。
  - 仍保留伴奏保护逻辑，只在检测到 vocal-like overlap 后启用更强抑制，避免普通伴奏被过度削弱。
- 歌词行内进度分词扩展：
  - 中文、日文、韩文按字符推进。
  - 英文、带重音拉丁文字、俄文、阿拉伯文等按词推进。

## 当前边界

- 如果原曲本身有和声、延迟效果或伴奏里强混响，该处理只能降低未跑调原唱尾音，不能完全删除音乐制作里本来存在的和声/回声。
