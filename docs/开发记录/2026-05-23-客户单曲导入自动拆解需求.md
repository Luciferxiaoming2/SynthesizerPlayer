# 2026-05-23 客户单曲导入自动拆解需求

## 本次目标

根据客户反馈，将产品入口从“导入已拆好的人声/伴奏双轨”升级为“导入一首完整歌曲，系统自动分离人声、伴奏并处理歌词”。

## 已更新文档

- `docs/需求文档 (PRD).md`
  - 在核心功能模块中加入“单曲导入自动拆解”。
  - 明确导入完整歌曲后自动做人声/伴奏分离。
  - 明确优先匹配本地歌词，缺失时进入自动歌词识别/转写。
- `docs/产品需求文档 (PRD)（包含技术版）.md`
  - 新增 F0：单曲导入与自动工程初始化。
  - 新增技术矩阵：单曲导入工程化、人声/伴奏分离、歌词识别/转写。
  - 新增实现方案：导入原曲、标准化音频、人声分离、歌词处理、进入双轨工程。
- `docs/开发记录/迁移与开发进度跟踪.md`
  - 新增 M13：单曲导入自动拆解。
  - 新增 P0：客户侧单曲导入自动拆解计划。

## 产品影响

这是普通用户最重要的入口体验。后续开发优先级应调整为：

1. 先做完整歌曲导入和工程目录。
2. 再做人声分离外部后端适配。
3. 再做歌词匹配/ASR 转写。
4. 最后将结果自动接入现有播放、跑调、VST 和导出链路。

## 当前边界

目前项目已经支持手动选择 vocal/instrumental/lyrics，也支持扫描已拆分歌曲目录；但“导入单首完整歌曲后自动拆分”还未实现，已记录为下一阶段 M13。
