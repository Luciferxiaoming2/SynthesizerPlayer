# 2026-05-25 save 目录收束与旧项目迁移

## 背景

用户发现便携版根目录出现 `projects` 以及无扩展名的音频文件，歌曲分离结果、歌词或旧生成内容散落在 `save` 之外。交付版需要保证歌曲相关数据统一放在 `save` 下，程序根目录只保留运行文件、依赖和必要配置。

## 修改

- 手动生成歌词时，输出路径改为 `save/<歌曲名>/lyrics.lrc` 或当前歌曲工程目录下的 `lyrics.lrc`。
- 不再根据根目录中的源音频位置把歌词写到程序根目录。
- 启动时自动迁移旧版 `projects/*` 到 `save/*`。
- 迁移旧项目后自动修复 `project.json` 中旧的绝对路径，避免移动后扫描不到歌曲。
- 启动时将根目录中旧版本遗留的无扩展名 WAV 输出移动到 `save/_legacy_root_outputs`。

## 验证

- 新增根目录音频生成歌词不污染根目录的测试。
- 新增旧 `projects` 迁移到 `save` 的测试。
- 新增根目录旧 WAV 输出迁移到 `save/_legacy_root_outputs` 的测试。
