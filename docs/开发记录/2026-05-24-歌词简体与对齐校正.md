# 2026-05-24 歌词简体与对齐校正

## 背景

用户反馈智能识别歌词中仍会出现繁体字，已唱过歌词过于醒目，且歌词与歌曲播放存在轻微不同步；对齐校正面板也缺少“0 秒，不做校正”的明确状态。

## 本次推进

- 扩展智能歌词识别后的繁体转简体兜底：
  - 新增词组级转换：`輪廓`、`看著`、`模樣`、`臉色`、`說不出`。
  - 扩展常见繁体字映射，减少中文歌曲识别后混入繁体的概率。
- 已唱过歌词改为缩小、变淡显示，当前句仍保持高亮。
- 对齐校正面板新增中间 `0s 不校正` 按钮。
- 对齐按钮接入真实歌词偏移：
  - `-0.5s`、`-0.1s` 表示歌词提前。
  - `0s` 表示不做校正。
  - `+0.1s`、`+0.5s` 表示歌词延迟。
- UI 会显示当前歌词偏移，播放时滚动歌词会按偏移重新计算。

## 说明

- 已经生成过的旧歌词文件不会自动重写；重新生成歌词后会应用新的简体归一化。
- 本批先提供手动歌词偏移校正，后续如需要自动校正，可继续做音频/歌词时间轴自动对齐。
