# 2026-05-23 Demucs 人声分离适配器

## 本次目标

在单曲导入工程入口的基础上，加入真实开源分离器 Demucs 的适配器，但不把 Demucs 依赖硬绑定到主项目，保持轻薄本和打包版本可控。

## 已完成

- 扩展 `core_engine/player/stem_separator.py`：
  - 新增 `DemucsSeparatorConfig`。
  - 新增 `DemucsStemSeparator`。
  - 默认命令为 `python -m demucs --two-stems vocals -n htdemucs -d cpu`。
  - 将 Demucs 输出的 `vocals.wav` / `no_vocals.wav` 归一化为项目内部的 `vocal.wav` / `instrumental.wav`。
- 扩展 `harness/cli_harness/import_song.py`：
  - `--backend demucs`
  - `--demucs-python`
  - `--demucs-model`
  - `--demucs-device`
- 扩展测试：
  - 覆盖 Demucs CPU 命令构造。

## 中文注释说明

本次在导入工程和 Demucs 适配逻辑中加入中文注释，说明为什么需要保留原曲副本、为什么分离器要做成可插拔端口，以及为什么要把 Demucs 输出文件名统一为项目内部命名。

## 当前边界

- 当前没有自动安装 Demucs，也没有下载模型权重。
- Demucs 在 CPU 上可跑但可能较慢；后续需要在目标轻薄本上实测耗时。
- 如果客户机器不能接受 Demucs 速度，可继续评估 UVR5 预处理包或云端分离方案。
