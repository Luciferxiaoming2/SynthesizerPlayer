# 2026-05-23 音频输出设备选择

## 本次目标

让 UI 不只依赖系统默认输出设备，用户可以刷新并选择 SoundDevice 可见的输出设备，降低真实播放时“没声音/出错到错误设备”的风险。

## 已完成

- 扩展 `core_engine/player/sounddevice_output.py`：
  - 新增 `AudioOutputDevice`。
  - 新增 `list_output_devices()`，延迟导入 sounddevice，并过滤仅输入设备。
- 扩展 `ui/main_window.py`：
  - 新增 `audioDeviceNames` 和 `selectedAudioDeviceIndex`。
  - 新增 `refreshAudioDevices()` 和 `selectAudioDevice(index)`。
  - `startAudioOutput()` 会使用当前选中的设备 id。
- 扩展 `ui/qml/SingleScreenUI.qml`：
  - 新增输出设备 ComboBox。
  - 新增 Devices 按钮用于刷新设备。
- 新增/扩展测试：
  - `tests/test_sounddevice_output.py`
  - `tests/test_ui_workbench.py`

## 本机验证

- 设备列表过滤测试通过。
- UI bridge 设备选择测试通过。
- UI smoke 加载成功。

## 当前边界

- 不在自动测试中打开真实声卡。
- 设备刷新结果依赖用户机器的 sounddevice/PortAudio 环境。
