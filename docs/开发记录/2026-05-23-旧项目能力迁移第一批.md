# 2026-05-23 旧项目能力迁移第一批

## 迁移原则

- `源代码/` 目录保持不变，只作为参考资料读取。
- 不搬运 VLC、ffmpeg、mp3 等旧二进制或音频资源到新代码结构。
- 只把旧项目中可复用的业务能力抽象到当前新架构中。

## 本批完成内容

从旧 `play.py` 参考并重建了以下能力：

- 歌词解析：
  - 新增 `core_engine/lyrics/parsers.py`
  - 支持 LRC 解析。
  - 支持 SRT 解析。
  - 修正旧解析器对三位毫秒 LRC 时间戳支持不足的问题，例如 `[00:00.042]`。
- 歌词时间轴：
  - 新增 `core_engine/lyrics/timeline.py`
  - 提供 `LyricLine` 和 `LyricTimeline`。
  - 支持按播放时间和 offset 获取当前歌词行。
- 歌词 offset 持久化：
  - 新增 `core_engine/library/offsets.py`
  - 用 JSON 保存和读取每首歌的歌词偏移。
- 歌曲目录扫描：
  - 新增 `core_engine/library/song_scanner.py`
  - 支持识别 `人声/伴奏`、`vocal/instrumental` 等命名。
  - 支持识别 `.lrc` / `.srt` 歌词文件。
- CLI：
  - 新增 `harness/cli_harness/scan_songs.py`
  - 可扫描旧歌曲目录并输出识别到的双轨资源。

## 配置调整

- `.gitignore` 增加 `源代码/`，避免旧项目大资源进入新项目版本管理。
- `scripts/validate_architecture.py` 忽略 `源代码/` 下的重型资源。
- `scripts/run_agent_checks.py` 排除 `源代码/`，避免把旧项目源码纳入新项目编译检查。
