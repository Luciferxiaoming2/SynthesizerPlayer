# 2026-05-24 参考图播放器界面重构

## 背景

用户提供了一张深色 Synthesizer Player 参考界面，希望最大可能还原：左侧歌曲库、中间滚动歌词主舞台、右侧 F0/DSP 面板、底部播放控制台；低频按钮放入右上角设置。

## 技术调研

- Python 桌面应用中类似 Element Plus / Ant Design 的现代 UI 方案包括：
  - PyQt-Fluent-Widgets：适合 QtWidgets/Fluent 风格。
  - qt-material：适合 QtWidgets 样式表。
  - Qt Quick Controls：当前项目已使用 QML，适合继续自定义控件、弹窗和播放器布局。
- 本项目现有 UI 是 PyQt6 + QML，如果切到 QtWidgets 风格库会重写大量界面和桥接层；因此本次保留 Qt Quick Controls，自定义播放器控件和图标化按钮。

## 本次推进

- 将主界面重构为三栏播放器：
  - 左侧：搜索框、当前歌曲库、导入歌曲主按钮、导入伴奏、扫描本地。
  - 中间：滚动歌词主舞台、当前歌词高亮卡片、对齐校正浮层。
  - 右侧：F0 音高基频监视器、DSP 参数、AI 自动修补原唱卡片、播放延迟状态。
  - 底部：进度条、播放/停止、音轨音量、VST 宿主、跑调破坏度滑杆。
- 右上角新增设置弹窗，收纳低频功能：
  - 歌曲导入/扫描/删除/清空。
  - 分离方式、歌词方式、生成歌词、导入歌词。
  - 输出设备、导出路径、VST 加载/移除。
  - 生成样例、对齐检测、未接入的真人唱功入口。
- 未接入功能继续置灰，例如“真人唱功：未接入”和底部循环按钮。
- 使用 QML 内置控件和文本符号实现图标化按钮，避免额外引入大型图标字体依赖。
