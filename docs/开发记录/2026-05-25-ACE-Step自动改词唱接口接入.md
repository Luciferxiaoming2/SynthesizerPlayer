# 2026-05-25 ACE-Step 自动改词唱接口接入

## 背景

ACE-Step 1.5 的 Gradio 工作台已经能在轻薄本 CPU 模式启动，但普通 `uv run acestep` 只开放网页界面，不开放桌面应用可直接调用的 REST 接口。

## 本次改造

- 应用右侧“AI 智能改唱工作舱”新增 ACE REST 接口检测：`http://127.0.0.1:7860/health`。
- 当 ACE 以 `uv run acestep --enable-api` 启动时，点击“调用 ACE 真唱并修补”会：
  - 上传当前人声音轨；
  - 按选中歌词的开始/结束时间提交 `repaint` 任务；
  - 轮询 `/query_result`；
  - 下载 `/v1/audio` 结果；
  - 将生成结果替换回当前句子并写入改词唱试听版本。
- 如果只启动了网页工作台但未启用 API，应用会明确提示需要用 `uv run acestep --enable-api` 重启，不再误走本机朗读。

## 注意

- CPU 模式推理会比较慢，应用内采用后台线程轮询，不阻塞主界面。
- 当前仍保留本机轻量改词唱作为备用路径；ACE API 就绪时优先使用 ACE。

## 验收

- 新增 ACE 结果解析测试。
- `tests/test_ui_workbench.py` 与 `tests/test_ai_singer_workflow.py` 共 72 条测试通过。
