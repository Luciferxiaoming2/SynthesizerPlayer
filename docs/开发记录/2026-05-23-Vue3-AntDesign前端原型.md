# 2026-05-23 Vue3 + Ant Design 前端原型

## 背景

用户希望使用合适的前端框架美化界面，并支持暗色与亮色两种主题。当前 PyQt6/QML 桌面版已经可运行，因此本次先新增独立 Web 前端原型，不破坏已有便携版交付链路。

## 本次调整

- 新增 `ui/web` 前端工程，技术栈为 Vue3、Vite、TypeScript、Ant Design Vue。
- 新增暗色/亮色主题切换，暗色保持当前 K 歌软件方向，亮色用于普通桌面办公环境。
- 前端布局包括歌曲库、滚动歌词、播放控制、分离后端、歌词后端、跑调强度、VST 导出入口和状态页。
- 未完成能力继续置灰或提示，例如真人唱功真实模型入口。
- `node_modules` 和 `ui/web/dist` 已加入 `.gitignore`，避免依赖和构建产物进入源码仓库。

## 当前限制

- 本次是前端原型层，尚未接入 Python 后端桥接 API。
- 当前环境 `npm install` 因权限/网络审核未完成，构建验证待用户本机执行或网络恢复后补跑。

## 后续

- 选择桌面集成方式：继续 PyQt 并嵌入 WebView，或切换到 Tauri/Electron。
- 定义 Python 后端 API：歌曲导入、播放控制、歌词状态、导出任务、VST 配置。
- 完成真实数据替换当前静态 mock 状态。
