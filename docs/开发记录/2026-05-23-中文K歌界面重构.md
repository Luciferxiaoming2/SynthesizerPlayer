# 2026-05-23 中文 K 歌界面重构

## 背景

参考用户提供的暗色 K 歌软件截图，将 PyQt6/QML 单屏工作台从工程调试界面改成更接近交付态的中文演唱助手界面。

## 本次调整

- 将主界面文案统一改为中文，标题更新为“AI主播演唱助手 - 真人唱功模拟”。
- 重构布局为左侧歌曲库、中间滚动歌词、底部播放与音频控制区。
- 保留已接入功能：选择目录、扫描、加载选中、导入歌曲、导入歌词、播放、真实音频、停止、生成样例、加载、导出、检测、后端选择、输出设备刷新。
- 对尚未完成的旧界面功能置灰：搜索、人声静音、伴奏静音、真人唱功开关、歌词字体、歌词偏移。
- 将跑调强度、人声、伴奏、主输出改成可拖动的真实滑杆，保持截图中的窄条视觉风格。
