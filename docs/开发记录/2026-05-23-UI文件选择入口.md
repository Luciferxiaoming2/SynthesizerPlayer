# 2026-05-23 UI 文件选择入口

## 本次目标

让普通用户不必手动复制路径，能在单屏 UI 中选择 vocal、instrumental、lyrics 和 output 文件。

## 已完成

- 扩展 `ui/main_window.py`：
  - 新增 `setPathFromUrl(target, url)`，统一处理 QML `FileDialog` 返回的 file URL。
  - 支持 `vocal`、`instrumental`、`lyrics`、`output` 四类路径更新。
- 重写 `ui/qml/SingleScreenUI.qml` 路径区域：
  - 增加 `QtQuick.Dialogs`。
  - 增加输入文件选择弹窗。
  - 增加输出 wav 保存弹窗。
  - 用内联 `PathPicker` 组件统一路径输入和选择按钮。
- 扩展 `tests/test_ui_workbench.py`：
  - 覆盖 bridge 从 file URL 更新路径。

## 本机验证

- UI bridge 文件 URL 测试通过。
- QML offscreen 加载成功。

## 对旧源代码迁移状态的影响

旧项目的歌曲文件选择/导入交互语义已经具备新 UI 第一版入口。后续仍需要把“按歌曲目录选择一首歌”的高级流程接入 UI。
