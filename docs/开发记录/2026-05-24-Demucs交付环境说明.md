# 2026-05-24 Demucs 交付环境说明

## 背景

默认导入后端切到 Demucs 后，开发环境可以依赖本机 `D:\uv\venvs\audio_forge` 运行真实人声分离。但面向普通用户交付时，不能要求用户自己安装 Python、Demucs、torch、ffmpeg 或模型权重。

## 当前开发阶段

- 可以继续使用本机开发环境：
  - `D:\uv\venvs\audio_forge\Scripts\python.exe`
  - 该环境已安装 Demucs、torch 等依赖。
- 启动脚本可通过 `AUDIO_FORGE_DEMUCS_PYTHON` 指向该环境，方便开发和验证。
- 这只是开发阶段方案，不是最终交付方案。

## 正式交付要求

便携包需要自带可运行环境，建议目录结构：

```text
AudioForgePortable_next\
  audio-forge-ui.exe
  启动 Audio Forge.bat
  save\
  python\
    python.exe
    Lib\site-packages\demucs\...
    Lib\site-packages\torch\...
  plugins\
    models\
      ffmpeg\ffmpeg.exe
      ffmpeg\ffprobe.exe
      torch\hub\checkpoints\*.th
      faster-whisper\small\...
```

验收标准：

- 用户解压后双击即可导入歌曲并执行真实人声/伴奏分离。
- 不要求用户安装 Python、Demucs、torch、ffmpeg 或手动下载模型。
- `save\` 用于保存导入歌曲工程，不进入 git。
- 如果完整包体过大，可以拆成基础包和模型环境包，但解压合并后仍必须开箱即用。
