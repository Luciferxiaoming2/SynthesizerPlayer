# 2026-05-25 改词唱咕咕声与短片段拉伸修复

## 问题

本机轻量改词唱使用 Windows SAPI 生成新词试听时，如果用户把一整句长歌词改成较短文本，生成的语音片段可能只有几秒，但原歌词时间段有十几秒或二十几秒。旧逻辑会把短语音强行拉伸到整句长度，容易产生“咕咕咕 / 啵啵”的失真声音。

另一个风险是系统没有匹配语言的语音包时，后端可能退到蜂鸣预览音，用户会误以为 AI 改唱坏了。

## 修复

- 本机轻量改词唱不再退到蜂鸣预览音，缺少系统中文/英文语音时直接提示环境未就绪。
- 本机语音生成的短片段不再做极端时间拉伸，改为按原速播放并用静音补齐剩余时间。
- 当前便携版测试歌曲已从失真改词试听轨切回原人声音轨，不需要重新导入歌曲。

## 验收

- 新增回归测试覆盖“短片段补静音而不是强行拉伸”。
- `tests/test_ai_singer_workflow.py` 与 `tests/test_ui_workbench.py` 共 70 条测试通过。
