# 2026-05-25 轻薄本本地改词唱方案与接入

## 目标

在不依赖 NVIDIA 显卡、大模型或云端服务的前提下，让用户在轻薄本上可以听到“新词被唱/读出来”的试听效果。

## 方案

本阶段采用轻量本地链路：

1. 选中一句歌词并输入新词。
2. 使用 Windows 本机 SAPI 语音合成生成新词短句。
3. 如果 SAPI 不可用，回退到内置 preview 合成，保证流程不断。
4. 将生成片段重采样到当前歌曲采样率。
5. 将片段裁剪/补齐到原歌词时间片段长度。
6. 叠加原人声片段的能量包络，让新词更贴合原句起伏。
7. 交叉淡入淡出替换原人声音轨中对应片段。

## 取舍

- 优点：本地可跑、无需显卡、无需大模型、交付体积小。
- 缺点：自然度低于云端大模型/专业 SVS，当前更像“按时间对齐的新词语音/半唱试听”。

## 当前状态

默认改词唱后端已从纯 preview 改为“本机轻量改词唱”。右栏生成试听后会产生实际被替换的人声音轨，点击播放即可听效果。
