# 2026-05-25 改词唱中文问号污染修复

## 问题

改词唱使用本机语音合成预览时，部分中文新词在 Windows 命令行参数传递过程中被转换成 `????`，导致 `lyrics.lrc` 第一行被写成问号，后续播放和歌词显示都受到污染。

## 修复

- 本机语音合成不再把中文歌词直接作为 PowerShell 命令行参数传入，改为写入 UTF-8 临时文本文件，再由 PowerShell 按 UTF-8 读取。
- 改词写回歌词前增加保护：如果新词只包含 `?` 或 `？`，拒绝覆盖正式歌词。
- 加载歌曲和生成歌词刷新时自动检查 `lyrics.lrc`，如果发现纯问号污染，会优先从 `lyrics.original.lrc` 恢复原句。
- 默认跑调程度调整为 `0%`，避免启动后用户误以为已开启跑调。

## 验收

- 已用中文歌词探测本机语音合成，输出 wav 正常生成。
- 已修复便携版 `save/离开我的依赖/lyrics.lrc` 第一行，恢复为原始中文歌词。
- 已补充回归测试，覆盖纯问号歌词拒绝写入和备份恢复。
