# 2026-05-23 统一音频导出工作流

## 本批目标

推进 M8：导出处理后音频。

## 完成内容

- 新增 `core_engine/exporter/audio_export.py`：
  - `AudioExportConfig`
  - `AudioExportResult`
  - `export_processed_mix`
- 新增统一导出流程：
  - 读取 vocal / instrumental。
  - 可选跑调。
  - 可选 vocal 效果链。
  - 可选 instrumental 效果链。
  - 混音。
  - 可选 master 效果链。
  - 写出 wav。
- 新增 `harness/cli_harness/export_mix.py`。

## 可运行看效果

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.generate_mock_audio --output-dir harness\mock_data

D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.export_mix --vocal harness\mock_data\vocal.wav --instrumental harness\mock_data\instrumental.wav --output harness\mock_data\export_mix.wav --tone-deaf-ratio 0.4 --master-gain-db -3
```

输出：

- `harness/mock_data/export_mix.wav`
