# 迁移与开发进度跟踪

## 目标

以 `源代码/` 旧项目作为功能参考，选择性吸收业务能力到当前新架构中。旧目录保持不变，不直接修改、不原样搬运 VLC/ffmpeg/歌曲资源/旧 PyQt5 UI。

当前新架构目标：

- `core_engine/`：无 UI 的播放、歌词、DSP、VST、AI 适配逻辑。
- `harness/`：命令行与评估脚手架。
- `ui/`：后续 QML/PyQt6 单屏界面。
- `docs/开发记录/`：记录每批迁移与开发动作。

## 迁移原则

- 旧代码只读参考，所有新增能力写入新项目结构。
- 优先迁移“业务语义”和“数据模型”，不迁移旧 UI 形态。
- 每批迁移后必须跑测试和 `agent-checks`。
- 每批迁移后更新本文档状态。
- 重型二进制和音频资源不进入新源码管理。
