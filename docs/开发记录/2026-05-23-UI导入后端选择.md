# 2026-05-23 UI 导入后端选择

## 本次目标

把单曲导入流程中的后端选择暴露到 UI，让用户/测试人员能够在界面中选择分离后端和歌词后端。

## 已完成

- 扩展 `ui/main_window.py`：
  - 新增 `separatorBackends`：`preview`、`demucs`。
  - 新增 `lyricsBackends`：`preview`、`faster-whisper`、`none`。
  - 新增 `importSongWithBackends(url, separator_backend, lyrics_backend)`。
  - 新增 `_build_separator()` 和 `_build_lyrics_transcriber()`。
  - GUI 中 Demucs 默认使用当前 Python + CPU，避免误用不可用 GPU。
- 扩展 `ui/qml/SingleScreenUI.qml`：
  - 导入区域新增两个 ComboBox。
  - `Import Song` 会把当前选择的后端传给 bridge。
- 扩展 `tests/test_ui_workbench.py`：
  - 覆盖 UI bridge 使用指定后端导入歌曲。

## 当前边界

- UI 尚未提供 Demucs 模型、设备、faster-whisper 模型大小等高级参数。
- 如果选择 `demucs` 或 `faster-whisper`，但环境没有安装依赖/模型，状态栏会显示错误。
- 普通用户默认仍应使用 `preview`，直到真实后端安装和实测完成。
