# 2026-05-25 改词唱失败提示修复

## 问题

用户在右侧“AI 智能改唱工作舱”生成改词唱时，界面弹出了“导入失败：没有找到选择的音乐文件”。实际操作并不是导入歌曲，而是改词唱内部遇到了 `FileNotFoundError` 后复用了导入流程的错误文案，导致提示误导用户。

## 修复

- `LyricRewriteWorker` 读取当前人声音轨前增加存在性校验。
- 改词唱失败回调改用 `format_lyric_rewrite_error()`，不再复用导入错误格式化。
- 缺少人声音轨、模型文件、外部工具失败等情况会显示“改词唱失败”语境。
- 导入异步入口增加源文件存在性前置检查，避免无效路径进入后台导入线程。
- 新增测试确保改词唱 `FileNotFoundError` 不再显示为“导入失败”。
