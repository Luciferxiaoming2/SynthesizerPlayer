# 2026-05-25 改词唱本机轻量后端默认选择修复

## 背景

用户选择右栏“内置安全预览”后，仍提示“当前AI改唱运行环境未就绪”。排查后确认右栏模型下拉框只是静态 UI 文案，并没有真实切换后端；同时本地存在 ACE-Step 模型文件夹时，程序会优先自动选择 ACE-Step，即使 ACE 推理环境和运行脚本未就位。

## 修改

- 将右栏和改词弹窗中的“AI 模型选择”改为只读的“本机轻量改词唱（无需显卡）”，避免误导用户以为可以通过下拉框切换模型。
- 更新改词唱说明文案，明确当前会生成本机试听音频并替换选中句子，效果属于轻量预览。
- 调整改词唱后端自动选择逻辑：只有 ACE-Step 模型和可执行环境都就绪时才自动启用 ACE-Step；如果只是下载了模型但运行环境未就位，则回落到本机轻量改词唱。

## 验证

- 后端探针显示当前默认后端为 `local_tts`，`can_replace_audio=True`。
- `tests/test_ai_singer_backend_config.py` 与 `tests/test_ui_workbench.py` 通过。
