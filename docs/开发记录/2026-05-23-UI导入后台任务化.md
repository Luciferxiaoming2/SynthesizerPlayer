# 2026-05-23 UI 导入后台任务化

## 本次目标

继续推进真实歌曲导入体验：Demucs 分离真实歌曲可能耗时较长，UI 不应在导入期间假死。本次先把 QML 的导入入口改为后台任务，并保留同步导入方法用于测试和内部调用。

## 已完成

- 扩展 `ui/main_window.py`：
  - 新增 `ImportSongWorker`，在 `QThread` 中执行 `import_single_song`。
  - 新增 `importSongWithBackendsAsync()`，供 QML 导入歌曲时调用。
  - 新增 `importBusy` 属性和 `importBusyChanged` 信号。
  - 导入中会显示 `Importing song...` 状态。
  - 导入完成后自动加载播放，并显示工程路径、分离后端和歌词后端。
  - 导入失败时把简短错误写入状态栏。
- 扩展 `ui/qml/SingleScreenUI.qml`：
  - `Import Song` 按钮改为调用异步导入入口。
  - 导入过程中按钮显示 `Importing` 并禁用，避免重复提交。
- 扩展 `tests/test_ui_workbench.py`：
  - 覆盖重复导入 busy guard。
