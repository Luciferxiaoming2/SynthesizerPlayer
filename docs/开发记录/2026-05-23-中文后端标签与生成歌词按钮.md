# 2026-05-23 中文后端标签与生成歌词按钮

## 背景

用户反馈界面里残留的英文后端名称看不懂，并希望在界面上直接提供“生成歌词”按钮；如果生成歌词有前置条件，需要在应用里明确提示。

## 本次推进

- QML 后端下拉框改为显示中文名称：
  - 分离方式：`快速预览`、`Demucs 人声分离`。
  - 歌词方式：`占位提示`、`本地识别`、`不生成歌词`。
- 内部仍保留 `preview`、`demucs`、`faster-whisper`、`none` 等稳定值，避免影响导入 manifest、CLI 和测试。
- 新增“生成歌词”按钮：
  - 当前歌词方式为“占位提示”时，会为已加载歌曲生成中文占位 LRC。
  - 当前歌词方式为“本地识别”但未安装 faster-whisper 时，会提示先安装依赖或切换到占位提示。
  - 当前歌词方式为“不生成歌词”时，会提示用户先切换歌词方式。
  - 未导入或未加载歌曲时，会提示先导入/加载歌曲。
- 导入、导出、对齐检测、文件选择、忙碌状态等 UI 状态文案进一步改为中文。
- 生成歌词时优先使用导入工程里保留的原曲/标准化音频，工程来源不可用时回退到当前人声轨。

## 后续

- faster-whisper 仍不内置安装；真实识别需要用户侧安装依赖和模型。
- 生成歌词当前在 UI 线程执行。占位生成很快；真实识别后续应改成后台任务，并显示“识别中/识别完成/未检测到歌词”的分阶段状态。
