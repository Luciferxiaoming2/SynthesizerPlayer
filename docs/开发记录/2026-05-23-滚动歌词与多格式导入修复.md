# 2026-05-23 滚动歌词与多格式导入修复

## 背景

用户反馈滚动歌词没有真正滚动，且从 `D:\music` 导入单首歌曲时部分文件导不进去。实际复现发现 MP3 可在当前环境直接读取，但 M4A 会触发 `Format not recognised`。

## 本次调整

- 将歌词区从静态当前句展示改为 `ListView`，绑定完整歌词列表和当前歌词索引，播放推进时自动滚动到当前行。
- `WorkbenchBridge` 新增 `lyricLines` 与 `currentLyricIndex`，供 QML 展示完整歌词时间轴。
- UI 导入非 wav 音频时自动查找项目本地 ffmpeg，并标准化为 `original_standard.wav` 后再进入分离/歌词流程。
- 增加中文错误转换：无法识别格式、缺少 ffmpeg、文件不存在、外部工具失败都会显示中文提示。
- 增加 QML 状态弹窗，重要状态和错误会弹出中文提示，同时保留底部状态栏。

## 本机验证

- `D:\music\Call of silence(最自由版).m4a`：UI 桥接导入成功。
- `D:\music\AISA_-_风恋歌.mp3`：CLI 标准化导入成功。
- `D:\music\多远都要在一起.m4a`：CLI 标准化导入成功。
- `D:\music\The Blacks ｜ Targaryen Theme ｜ House of the Drago.mp3`：CLI 标准化导入成功。

## 后续

- 当前 preview 歌词后端只生成占位歌词；要得到真实逐句滚动，需要同名 `.lrc/.srt` 或接入 faster-whisper 真实转写。
- 后续可增加导入前文件类型预检，并在 UI 中展示“正在转码/正在分离/正在生成歌词”的分阶段进度。
