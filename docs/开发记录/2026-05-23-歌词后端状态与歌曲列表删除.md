# 2026-05-23 歌词后端状态与歌曲列表删除

## 背景

用户反馈选择 `faster-whisper` 后不知道是否起作用，未安装依赖时界面弹出完整 traceback；同时左侧歌曲列表缺少删除和清空能力。

## 本次调整

- 选择 `faster-whisper` 时检查依赖是否存在，未安装时显示中文提示，不再启动导入任务。
- `faster-whisper` 运行失败时转换为中文错误：“歌词识别失败：faster-whisper 未安装或不可用”。
- UI 增加歌词后端状态文案，显示当前后端是否会真实识别歌词。
- 左侧歌曲库增加“删除选中”和“清空列表”按钮。
- 删除正在播放的歌曲时会停止当前播放，并自动加载下一首；清空列表不会删除磁盘文件。

## 验证

- `D:\uv\venvs\audio_forge\Scripts\python.exe -m pytest tests\test_ui_workbench.py`
- `QT_QPA_PLATFORM=offscreen AUDIO_FORGE_UI_SMOKE=1 D:\uv\venvs\audio_forge\Scripts\python.exe -m ui.main_window`

## 后续

- 可在依赖安装工具里增加 faster-whisper 一键安装入口。
- 歌词后端可进一步显示“识别中/识别完成/未检测到歌词”的分阶段状态。
