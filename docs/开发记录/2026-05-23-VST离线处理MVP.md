# 2026-05-23 VST 离线处理 MVP

## 本批目标

推进 M7：VST 离线处理 MVP。

## 完成内容

- 升级 `core_engine/dsp/vst_host.py`：
  - 新增 `OfflineEffectConfig`
  - 新增 `apply_gain`
  - `VstEffectChain` 支持基础离线 gain 处理。
  - `VstEffectChain` 支持可选 `pedalboard` 加载 VST 插件。
  - 如果没有安装 `pedalboard`，只有在实际传入插件路径时才报错。
- 新增 `harness/cli_harness/render_effect_chain.py`：
  - 支持输入 wav。
  - 支持 `--gain-db`。
  - 支持多个 `--plugin` 路径。
  - 输出处理后的 wav。

## 可运行看效果

先生成 mock 音频：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.generate_mock_audio --output-dir harness\mock_data
```

渲染一个降低 6dB 的人声文件：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.render_effect_chain --input harness\mock_data\vocal.wav --output harness\mock_data\vocal_gain.wav --gain-db -6
```

如果用户本机有 VST3 插件并已安装 `pedalboard`，可以追加：

```powershell
D:\uv\venvs\audio_forge\Scripts\python.exe -m harness.cli_harness.render_effect_chain --input input.wav --output output.wav --plugin "C:\Path\To\Plugin.vst3"
```
