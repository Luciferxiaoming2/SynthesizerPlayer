# 2026-05-24 歌词识别提示词过滤与滚动修正

## 背景

用户反馈生成歌词后出现“请使用繁体中文或英文，不要使用繁体中文。”这类提示词文本，说明 ASR 初始提示被模型误当作歌词输出；同时对齐校正区域组件有重叠，播放时生成歌词仍可能不主动滚动。

## 本次推进

- 移除 faster-whisper 的 `initial_prompt`，避免提示词被识别成歌词。
- 增加提示词幻觉过滤：包含“请使用简体中文或英文”“不要使用繁体中文”“输出歌词”等指令文本的片段会被丢弃。
- 保留生成后文本规范化和常见繁体转简体，目标输出仍是简体中文或英文。
- 调整 faster-whisper 解码参数：
  - `beam_size=8`
  - `best_of=5`
  - `condition_on_previous_text=False`
  - 设置 no-speech 和压缩率阈值，减少无歌词或静音片段幻觉。
- 对齐校正面板改成上下两行布局，按钮按宽度均分，避免标题和按钮重叠。
- QML 监听 `lyricPositionChanged` 后主动 `positionViewAtIndex`，强化播放时歌词跟随滚动。
