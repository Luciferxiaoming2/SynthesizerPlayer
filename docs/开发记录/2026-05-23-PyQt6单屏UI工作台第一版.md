# 2026-05-23 PyQt6 单屏 UI 工作台第一版

## 本次目标

把 `ui.main_window` 从占位异常推进到可启动的单屏工作台，让项目开始具备面向普通用户的图形入口。

## 已完成

- 重写 `ui/main_window.py`：
  - 新增 `WorkbenchBridge`，作为 QML 和 `core_engine` 之间的轻量桥接层。
  - 支持生成 mock 双轨音频。
  - 支持按跑调强度和 master gain 导出混音 wav。
  - 启动时使用 `QT_QUICK_CONTROLS_STYLE=Basic`，避免 Windows Controls 样式插件在本机环境加载失败。
- 重写 `ui/qml/SingleScreenUI.qml`：
  - 单屏布局，包含 Stems 和 Render 两个工作区。
  - 可编辑 vocal、instrumental、output 路径。
  - 提供 tone drift 和 master gain 滑块。
  - 提供 Mock 和 Export 操作按钮。
- 新增 `tests/test_ui_workbench.py`：
  - 覆盖桥接层生成 mock 音频与导出混音的核心行为。

## 本机验证

- 已用 offscreen 模式加载 QML，确认 `SingleScreenUI.qml` 可创建 root object。
- UI 桥接层测试覆盖了 mock 生成和导出链路。
