# 2026-05-23 UI 歌曲库扫描与选择

## 本次目标

把旧项目中的“扫描歌曲目录并选择歌曲”能力接入新 UI，不再只依赖手动填写 vocal、instrumental 和 lyrics 路径。

## 已完成

- 扩展 `ui/main_window.py`：
  - 新增 `songsRoot` 和 `songNames`。
  - 新增 `setSongsRootFromUrl()`，用于接收 QML 文件夹选择结果。
  - 新增 `scanSongs()`，调用 `core_engine.library.song_scanner.scan_song_library`。
  - 新增 `loadSongAt(index)`，自动填充 vocal、instrumental、lyrics 和默认导出路径，并加载播放状态。
- 扩展 `ui/qml/SingleScreenUI.qml`：
  - 新增 `FolderDialog` 选择 songs 根目录。
  - 新增歌曲 ComboBox。
  - 新增 Scan 和 Use 操作。
- 扩展 `tests/test_ui_workbench.py`：
  - 覆盖 UI bridge 扫描歌曲目录并加载选中歌曲。

## 本机验证

- UI bridge 歌曲扫描/加载测试通过。
- QML offscreen 加载成功。

旧项目的歌曲目录扫描、歌曲选择、双轨路径和歌词路径自动装载，已经完成新架构第一版迁移。旧 UI 形态没有原样迁移，业务语义已进入 `core_engine/library` 与 QML bridge。
