# 2026-05-24 Demucs 导入进度与错误详情

## 背景

用户导入歌曲时看到控制台输出：

```text
Separated tracks will be stored in ...\save\心之火_3\stems\_demucs\htdemucs
Separating track ...\save\心之火_3\original_standard.wav
```

这说明 Demucs 已开始真实分离，但 UI 没有进度提示，容易误以为卡死或失败；同时失败提示过于笼统，不利于定位是环境问题、模型问题、内存问题还是音频文件问题。

## 本次推进

- 导入歌曲时新增进度状态：
  - 创建歌曲工程。
  - 分离人声和伴奏。
  - 加载分离结果。
- QML 在导入按钮下显示进度条。
- Demucs 真实分离阶段使用不确定进度条，因为 CPU 分离耗时取决于歌曲长度，不能稳定给出精确百分比。
- Demucs 子进程失败时捕获 stdout/stderr 末尾日志，并写入中文失败提示。

## 验证

- 新增 UI bridge 测试覆盖导入进度状态。
- 新增错误格式化测试，确保 Demucs 失败详情不会被吞掉。

## 说明

- 真实分离较慢是正常现象；长歌在 CPU 上可能需要几分钟。
- 当前开发阶段仍可依赖本机 `D:\uv\venvs\audio_forge`，正式交付必须内置 sidecar Python/Demucs 环境。
