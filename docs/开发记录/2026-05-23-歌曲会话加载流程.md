# 2026-05-23 歌曲会话加载流程

## 本批目标

推进 P2：歌曲导入/选择流程。

## 完成内容

- 新增 `core_engine/library/song_session.py`。
- 新增 `SongSession`，统一封装：
  - 歌曲资源路径。
  - 歌词 offset。
  - 歌词时间轴。
  - 歌词播放同步器。
- 新增 `select_song_by_name`，可从歌曲目录选择指定歌曲。
- 新增 `harness/cli_harness/load_song_session.py`，可命令行加载歌曲会话并打印当前歌词状态。

## 设计原则

- 不复制旧 mp3。
- 不读取音频内容。
- 只建立路径、歌词和 offset 元数据。
- 后续 UI 可直接使用 `SongSession`。
