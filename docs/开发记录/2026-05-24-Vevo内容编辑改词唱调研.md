# 2026-05-24 Vevo/内容编辑改词唱调研与接入进度

## 调研结论

- B 站“AI 改词翻唱/声虎 AI/Vevo1.5”这类效果，核心更接近“内容编辑”：输入原唱片段和新歌词，输出保留音色、节奏、伴奏上下文的新唱句。
- RVC / So-VITS-SVC 更适合作为音色转换后处理：它能把已经唱好的声音换成目标音色，但不能单独解决“歌词变了以后要重新唱准”的问题。
- DiffSinger / OpenUtau 类 SVS 更适合从歌词、音高、时值重新合成唱声，再用 RVC 做音色转换。可控性强，但前置旋律、音素和模型准备更重。
- Vevo1.5 一类零样本声音模仿/内容编辑方案更贴近本项目的“选一句歌词直接改唱”，后续优先把它作为真实后端接入目标。

## 本次工程推进

- 新增 `content_edit` 改词唱后端类型，并兼容 `vevo`、`vevo1.5`、`vevo15`、`external_content_editor` 等别名。
- 新增外部内容编辑命令适配器。命令模板可使用：
  - `{source}`：当前选中歌词对应的原始人声片段
  - `{lyric}`：用户输入的新歌词
  - `{melody}`：当前人声音轨路径，可供后端提取旋律/韵律
  - `{output}`：后端需要写出的改唱片段
  - `{sample_rate}`、`{duration}`、`{start_ms}`、`{end_ms}`：音频和时间信息
- UI 右栏模型选项调整为：
  - Vevo1.5/内容编辑（需外部后端）
  - 唱声合成 + RVC 音色转换
  - 内置实验预览
- 当前没有随包内置真实 Vevo 模型，因此默认仍是“内置实验预览”。这只是验证 UI、分段替换、版本管理和试听流程，不代表真实改词质量。

## 后续交付注意

真实交付版需要把模型、推理环境、依赖和命令模板一起打包或放入 `plugins`，用户不应自行配置 Python 环境。建议优先寻找可离线运行、命令行稳定、许可证允许分发的 Vevo/内容编辑实现；如果无法稳定交付，再退回 DiffSinger + RVC 的可控路线。
