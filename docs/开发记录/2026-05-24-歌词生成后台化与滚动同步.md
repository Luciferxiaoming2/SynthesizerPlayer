# 2026-05-24 歌词生成后台化与滚动同步

## 背景

用户反馈点击“生成歌词”后应用会卡死；希望生成歌词时能看到进度条；生成歌词应尽量保持简体中文或英文；播放音乐时，新生成歌词没有跟随同步滚动。

## 本次推进

- 歌词生成改为后台线程：
  - 新增 `LyricsGenerationWorker`，ASR 识别不再阻塞 QML 主线程。
  - 新增 `lyricsGenerationBusy`、`lyricsGenerationProgress`、`lyricsGenerationStatus` 属性。
  - 重复点击生成歌词时会提示“歌词正在生成中，请稍等”。
- UI 进度：
  - 滚动歌词主舞台顶部新增生成进度区域。
  - 显示当前阶段：准备音频、正在识别、整理时间轴。
  - 识别阶段使用动态进度条，避免用户误以为应用卡死。
- 歌词文本：
  - faster-whisper 调用增加提示词，要求输出简体中文或英文。
  - 生成后做基础文本规范化和常见繁体字转简体，避免 LRC 中混入繁体或控制字符。
- 滚动同步：
  - 歌词 ListView 在当前行变化时主动定位到当前歌词行，播放时新生成歌词也会跟随滚动。
