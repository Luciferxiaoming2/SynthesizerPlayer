# 2026-05-24 MP3 导出入口

## 背景

进度文档中 M8 “导出处理后音频”已完成 wav 输出，但后续计划里仍保留通过 ffmpeg 接入 mp3 导出。普通用户更常用 mp3，因此本次补齐 UI 和核心导出层的 mp3 目标路径。

## 本次推进

- 新增 `FfmpegMp3Encoder`，复用项目本地或 PATH 中的 ffmpeg。
- `AudioExportConfig` 新增可选 `mp3_encoder`。
- `export_processed_mix()` 支持 `.mp3` 输出：
  - 先按现有流程渲染临时 wav，保证跑调、VST、增益等处理一致。
  - 再用 ffmpeg 编码为 192k mp3。
  - 如果目标是 mp3 但没有 encoder，会给出明确错误。
- UI 导出文件选择支持 `*.mp3` 和 `*.wav`。
- `WorkbenchBridge.exportMix()` 根据导出后缀自动创建 mp3 encoder；找不到 ffmpeg 时转换为中文提示。
