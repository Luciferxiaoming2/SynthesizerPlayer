# 2026-05-23 歌词自动转写适配层

## 本次目标

补齐 M13 “导入完整歌曲后自动准备歌词”的工程接口。当前先实现 preview 占位歌词和外部 ASR 命令适配，后续可接 faster-whisper/Whisper。

## 已完成

- 新增 `core_engine/transcription/lyrics_transcriber.py`：
  - `LyricsTranscriber` 抽象端口。
  - `PreviewLyricsTranscriber`，在没有 LRC/SRT 时生成可编辑的初始 LRC。
  - `FasterWhisperLyricsTranscriber`，可选接入本地 faster-whisper。
  - `ExternalCommandLyricsTranscriber`，预留 `{audio}`、`{output}`、`{output_dir}` 命令模板。
- 扩展 `core_engine/importer/song_importer.py`：
  - `SongImportConfig` 新增 `lyrics_transcriber`。
  - 找不到同名 `.lrc` / `.srt` 时，可调用转写后端生成 `lyrics.lrc`。
- 扩展 `harness/cli_harness/import_song.py`：
  - 新增 `--lyrics-backend none|preview|faster-whisper|external`。
  - 新增 `--whisper-model`、`--whisper-device`、`--whisper-compute-type`、`--whisper-language`。
  - 新增 `--lyrics-command`。
  - 默认 preview，保证客户侧“导入一首歌后有歌词时间轴可编辑”的流程先跑通。
- 扩展 UI：
  - `Import Song` 默认使用 `PreviewLyricsTranscriber`。
- 新增测试：
  - `tests/test_lyrics_transcriber.py`
  - 扩展 `tests/test_song_importer.py`

## 中文注释说明

在 preview 转写和 importer 中加入中文注释，明确 preview 不是 ASR 结果，只是让无歌词歌曲也能进入可编辑时间轴；后续接 faster-whisper 时替换 adapter 即可。

## 当前边界

- preview 歌词不是自动识别内容。
- faster-whisper adapter 已接入，但依赖和模型不默认安装/下载。
- ASR 在 Intel 轻薄本上需要实测模型大小和速度，建议默认 base/int8/cpu，不默认下载大模型。
