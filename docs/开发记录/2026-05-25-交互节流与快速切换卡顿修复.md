# 2026-05-25 交互节流与快速切换卡顿修复

## 背景

用户反馈歌曲切换过快或连续点击按钮时，程序可能卡住。

## 调研结论

Qt/PyQt 桌面应用的常见处理是：

- 耗时任务放到 `QThread` 或后台任务，避免阻塞 UI 线程。
- 对按钮点击做 debounce/throttle，避免同一操作被连续触发。
- 在加载、导入、渲染期间禁用或忽略冲突操作。

## 本次处理

- QML 层增加 `acceptUiAction()`，对播放、切歌、扫描、删除等高频按钮做短时间冷却。
- Python 桥接层增加手动切歌冷却和 `_navigation_busy` 锁，避免连续触发 `loadPlayback()`。
- 程序内部自动列表播放/单曲循环不走手动节流，避免破坏正常播放逻辑。
- 正在导入或跑调渲染时，手动切歌会提示“正在处理上一项操作，请稍等”。

## 当前效果

快速连点不会连续排队多个音频加载任务，按钮反馈会更平滑，减少 UI 卡住概率。
