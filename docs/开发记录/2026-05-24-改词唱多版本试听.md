# 2026-05-24 改词唱多版本试听

## 本次目标

- 继续完善改词唱功能，让用户可以保留并比较多个试听结果。
- 避免同一句歌词多次生成时覆盖上一次结果。

## 已完成

- 改词唱输出文件改为按版本保存：首次为 `*_rewrite_XXX.wav`，后续为 `*_rewrite_XXX_v02.wav`、`v03.wav` 等。
- 改词唱弹窗新增“已生成的试听版本”列表。
- 点击历史试听版本可立即套用到当前人声音轨，并重新加载播放器。
- 套用历史版本时会读取同名 `.json` manifest，将对应新歌词写回当前歌词文件，并刷新滚动歌词。
- 生成新版本时优先以原始人声音轨为基础，减少连续多次生成导致的音频劣化。
- 改词唱弹窗新增“版本文件夹”入口，便于直接查看生成的 wav/json 试听文件。
- 左侧歌曲库新增“打开文件夹”和“当前歌曲目录”，方便用户管理 `save` 中的导入工程与素材。
- 新增 UI 桥接测试，覆盖多版本生成、版本列表和切换旧版本。

## 当前限制

- 版本列表暂不支持删除、重命名和评分。
- 当前仍以整句歌词时间片段替换为主，尚未做音素级对齐。
- 默认后端仍是 preview；真实改词唱效果需要后续接入外部唱声合成或音色转换模型。
