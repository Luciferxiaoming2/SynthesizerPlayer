# 2026-05-23 改词唱实验性适配层

## 本次目标

在不依赖训练、不要求 GPU、不绑定具体开源仓库的前提下，先把“改词唱”的工程接口跑通。MVP 阶段默认提供轻量 preview 后端，真实 DiffSinger/RVC 后续通过外部命令适配器接入。

## 已完成

- 扩展 `core_engine/ai_singer/diff_singer_api.py`：
  - 新增 `PreviewSingingClient`，可根据歌词生成确定性的占位人声 wav。
  - 新增 `ExternalDiffSingerClient`，支持 `{lyric}`、`{melody}`、`{output}` 等占位符命令模板。
- 扩展 `core_engine/ai_singer/rvc_infer.py`：
  - 新增 `BypassRvcInferencer`，用于没有 RVC 后端时保持流程可跑。
  - 新增 `ExternalRvcInferencer`，支持 `{source}`、`{model}`、`{output}` 命令模板。
- 新增 `core_engine/ai_singer/workflow.py`：
  - 定义 `LyricRewriteSingingRequest` 和 `LyricRewriteSingingWorkflow`。
  - 串联“唱法合成”和“可选音色转换”两个阶段。
- 更新 `harness/cli_harness/run_lyric_ai.py`：
  - `preview` 模式现在可以直接生成 wav。
  - `external` 模式可对接后续开源推理脚本。
- 新增 `tests/test_ai_singer_workflow.py`：
  - 覆盖 preview 生成。
  - 覆盖 RVC bypass 串联。

## 当前边界

- preview 后端只是工程占位音频，不是真实歌声。
- 真实改词唱仍需要选择合适的外部推理项目和模型权重。
- 当前设计不会把大模型默认纳入打包，符合 Intel 轻薄本和普通用户分发目标。

## 下一步建议

优先进入 PyInstaller/发布结构准备和 UI MVP。真实改词唱可作为“实验功能”，在基础播放、跑调、VST、导出稳定后再接具体开源后端。
