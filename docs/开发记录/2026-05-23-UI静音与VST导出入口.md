# 2026-05-23 UI 静音与 VST 导出入口

## 背景

继续按迁移进度推进 PyQt6/QML 单屏工作台，把已经存在于后端的音频控制能力接入界面，减少灰色占位按钮。

## 本次调整

- 将“人声静音”和“伴奏静音”从置灰按钮改为可用按钮。
- 静音按钮接入 `DualTrackPlaybackEngine.set_mute`，播放和无声预览均可立即听到/看到状态变化。
- 新增 UI 侧主输出 VST 插件选择入口，支持选择 `.vst3` / `.dll`。
- 主输出 VST 仅在“导出”时生效，沿用现有 `AudioExportConfig.master_plugins` 离线处理链路，不影响实时播放稳定性。
- 新增移除 VST 按钮和中文状态提示。
