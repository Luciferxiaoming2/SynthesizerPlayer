# 2026-05-24 save 目录与真实分离默认值

## 背景

用户反馈导入歌曲后，人声和伴奏互相串音：关闭人声后伴奏里仍有人声，反过来也一样。排查后确认当前默认后端是 `preview`，它只是轻量测试分离，不是真实消人声。

同时，便携版默认歌曲库目录使用中文 `导入歌曲`，用户建议改为英文 `save`，并希望每次启动应用自动加载该目录。

## 本次推进

- 默认导入工程目录改为程序根目录下的 `save`。
- 应用启动时自动创建并扫描 `save`。
- 默认分离后端从 `preview` 改为 `demucs`。
- `preview` 的 UI 文案改为 `快速预览（不消人声）`。
- `demucs` 的 UI 文案改为 `真实人声分离（较慢）`。
- 左侧导入按钮改为 `真实分离导入歌曲`。
- 右栏预设改为 `快速预览 / 真实分离`，避免“标准人声/极致消除”造成误解。

## 验证

- `D:\uv\venvs\audio_forge\Scripts\python.exe -m pytest tests\test_ui_workbench.py`：42 passed。
- `AUDIO_FORGE_UI_SMOKE=1 D:\uv\venvs\audio_forge\Scripts\python.exe -m ui.main_window`：`Audio Forge UI smoke loaded`。

## 说明

- Demucs 是真实分离，CPU 上会慢一些，但才适合正式导入。
- 快速预览只用于快速测试导入流程，不保证人声/伴奏干净。
