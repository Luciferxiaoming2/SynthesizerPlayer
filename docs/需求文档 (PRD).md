## 🎵 核心需求文档 (PRD)

### 1. 产品定位

一款面向创作者和音频极客的桌面端智能音频工作站。核心体验聚焦于**单屏沉浸式交互**，通过极简、现代、充满未来感的界面，让用户能够对现有歌曲进行深度的“外科手术式”二次创作与恶搞。所有操作在单一视窗内完成，摒弃繁杂的深层菜单与滚动条。

### 2. 核心功能模块

#### 模块一：智能多轨控制与播放

- **单曲导入自动拆解**：用户只需要导入一首完整歌曲（MP3/WAV/FLAC 等），软件自动完成工程初始化，不要求用户提前准备人声轨、伴奏轨或歌词文件。
- **AI 音轨分离**：导入完整歌曲后，软件自动在后台将其拆分为“人声”与“伴奏”两个独立轨道，并缓存为可复用的本地工程资产。
- **歌词生成/匹配**：导入歌曲后，系统优先查找同目录歌词文件（`.lrc` / `.srt`）；如果没有歌词文件，则进入自动歌词识别/转写流程，生成可编辑歌词时间轴。
- **独立混音**：支持分别控制人声和伴奏的音量，支持单轨静音（Mute）或独奏（Solo）。
- **无缝同步**：两条轨道必须在播放引擎中严格对齐，保证零延迟同步播放。

#### 模块二：时间轴动态歌词系统

- **右侧单屏展示**：歌词面板固定在界面右侧，以平滑滚动的方式显示当前进度。
- **可视化时间轴拖拽**：如果发现歌词与声音对不齐，用户可以直接在歌词面板拖拽某句歌词的“时间块”，实现视觉化的毫秒级时间轴微调。

#### 模块三：“五音不全”跑调模拟器

- **跑调控制器**：提供一个极具质感的滑块控制旋钮，设置 1% - 80% 的“跑调比例”。
- **物理级真实感**：区别于传统的整体升降调（Pitch Shift），该功能必须模拟人类唱歌时真实的走音感（音高漂移、找不到调、颤音失控）。
- **实时同步**：处理后的人声必须与伴奏紧密贴合，不能出现拍子错位。

#### 模块四：AI 歌词篡改与原声克隆

- **双击重写**：在右侧歌词面板，双击任意一句原歌词（如“我爱你”），将其修改为新文本（如“一二三”）。
- **智能代唱**：软件自动提取该句的原曲旋律，并让 AI 按照原唱的音色和旋律，把新词（“一二三”）唱出来。
- **无缝替换**：播放到该句时，自动用 AI 合成的声音替换原声音轨，实现“偷天换日”。

#### 模块五：VST 音频效果器宿主

- 支持加载外部标准的 `.dll` 或 `.vst3` 音频效果器插件。
- 用户可以将混响、Auto-Tune 等效果器独立挂载在人声或伴奏轨道上，拓展处理能力。

## 🛠 技术规格与开源整合指南 (Tech Spec)

整体技术栈推荐使用 **Python**，这非常契合命令行快速构建与测试（Vibecoding）的节奏，并且 Python 在 AI 语音与信号处理生态中拥有绝对优势。

### 1. UI 与底层架构选型

- **GUI 框架**：`PyQt6` 或 `PySide6`。
  - *建议*：为了实现你想要的“无滚动、未来感、单屏全显”的现代 UI，建议结合 QML 来编写界面，它的动画性能和对高质感 UI（毛玻璃、流光效果）的支持远超传统 QWidget。
- **音频播放引擎**：`SoundDevice` 结合 `PySoundFile`。用于构建底层的双轨 Buffer 同步播放机制。

### 2. 核心难点与开源项目映射

| **需求模块**       | **推荐开源项目 / 库**                                        | **技术实现路径**                                             |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **单曲导入工程化** | `soundfile` / `ffmpeg` / 自研工程缓存                         | 导入完整歌曲后创建工程目录，保存原曲、分离结果、歌词、offset 和处理缓存。 |

### 3. 高阶 AI 功能深度解析

#### 3.1 真实跑调算法 (F0 Manipulation)

要做到“真实的五音不全”，需要对人声的声学特征进行解构与重建。

- **核心库**：`pyworld` (基于 WORLD 声码器) 或 `Librosa`。
- **实现步骤**：
  1. 使用 `pyworld.wav2world` 提取人声的 F0（基频/音高）曲线、SP（频谱包络）和 AP。
  2. 生成一段低频的 Perlin 噪声或正弦波复合振荡器。
  3. 根据 1-80% 的比例，将噪声叠加到 F0 曲线上。比例越大，F0 偏离标准音高的音分（Cents）就越严重，人为制造“音准漂移”。
  4. 使用 `pyworld.synthesize` 结合修改后的 F0 重新合成音频。

#### 3.2 歌词篡改与音色克隆 (SVS + SVC)

这是整个项目工程量最大的一环，需要将两个顶级的开源 AI 声音项目串联。

- **前置旋律合成**：`DiffSinger` (OpenVPI 开源)
  - 双击修改歌词后，后台提取该句原唱的 MIDI 旋律线和 BPM。
  - 将新文本与 MIDI 送入 DiffSinger，合成出音调正确但音色通用的干声。
- **后置音色替换**：`SO-VITS-SVC` 或 `RVC` (Retrieval-based Voice Conversion)
  - 提前使用原唱的音频提取声纹特征（Index）。
  - 将 DiffSinger 生成的通用干声作为输入，通过 RVC 模型，将其“渲染”成原唱的音色。
  - 在播放引擎中，精准替换掉原对应时间戳的音频块。

### 开发节奏建议

如果采用敏捷开发模式，建议的第一步是在终端里先把 `Spleeter`（分离）和 `SoundDevice`（双轨同步播放）跑通，确保底层引擎在没有 UI 的情况下也能输出不掉帧、不延迟的音频流。底层逻辑稳固后，再套上高质感的 PyQt 界面。
