# Synthesizer Player UI 设计文档

本文档记录当前桌面版 UI 的布局、视觉风格和主要功能界面设计，便于后续继续开发、验收和交付时保持一致。

## 1. 整体设计目标

应用定位为面向普通用户的音乐处理与试听工具，核心任务包括歌曲导入、人声/伴奏分离、歌词滚动播放、跑调程度调节、歌词改唱试听和导出。界面采用单窗口工作台设计，避免多窗口来回切换。

当前 UI 使用深色主题作为默认视觉方案，强调舞台感和音频软件的专业感。主色为高亮粉色，用于当前选中、主要按钮、改词唱入口和重点状态提示；白色用于主要文字、播放按钮和滑条已调整部分；深灰用于背景、卡片和未激活轨道。

窗口基础设计尺寸为 `1480 x 920`，最小尺寸为 `920 x 620`。界面通过统一 `uiScale` 随窗口大小缩放，保证主要面板和控件在小屏、轻薄本屏幕和大屏中保持比例一致。

## 2. 主界面布局

主界面采用四区结构：

- 顶部栏：应用标题、主题/设置入口等全局操作。
- 左侧栏：歌曲库、导入、扫描、打开目录、删除歌曲等文件管理操作。
- 中间舞台：滚动歌词、当前歌词高亮、歌词进度效果、对齐校正。
- 右侧栏：根据状态切换为 DSP 参数面板或 AI 智能改唱工作舱。
- 底部栏：播放控制、播放进度、人声/伴奏/主输出滑条、VST 入口、跑调程度调节。

整体布局优先保证中间歌词舞台的空间，其次是右侧改词工作舱。左侧栏宽度固定，右侧栏固定为较窄工具区，底部栏固定高度以便播放时长期可见。

## 3. 左侧歌曲库

左侧栏标题为“保存歌曲库”，用于展示当前 `save` 歌曲库中的歌曲工程或普通音频文件。

主要控件包括：

- 搜索占位框：当前主要作为视觉入口，后续可扩展真实搜索。
- 导入按钮：导入音频并进行人声/伴奏分离。
- 扫描 save：重新扫描歌曲库。
- 打开文件夹：打开当前歌曲库根目录。
- 当前歌曲目录：打开当前选中歌曲所在目录。
- 删除选中：删除当前歌曲库中选中的歌曲工程或音频文件。
- 清空列表：删除当前列表中的歌曲工程或音频文件。

删除相关操作必须弹出二次确认。用户点击确认后才会真实删除磁盘文件，同时清理播放状态、歌词状态和 AI 改唱状态。

歌曲列表项显示歌曲名、当前播放状态和时长。当前选中项使用粉色边框和深粉背景强调。

## 4. 中间歌词舞台

中间区域是应用的主视觉中心，用于显示歌词和播放状态。

设计要点：

- 歌词以大字号显示，当前句位于视觉中心附近。
- 当前歌词行带粉色半透明背景框，右侧显示该句时间。
- 已唱过的中文按字、英文按单词进行视觉进度变化。
- 长歌词在可视区域内裁切或滚动，避免文字遮挡右侧时间与边界。
- 无歌词时显示“纯音乐或暂无歌词”。
- 双击或点击歌词行会选中该句，并触发右侧切换为 AI 智能改唱工作舱。

中间区域下方提供“对齐校正”工具，包含 `-0.5s`、`-0.1s`、`0s`、`+0.1s`、`+0.5s` 快捷按钮。`0s` 表示不做校正，是默认状态。

## 5. 右侧默认面板：DSP 实时声学参数

未选择歌词改唱时，右侧栏默认展示实时参数和辅助功能，标题为“DSP 实时声学参数”。

当前主要承载：

- 实时声学/波动展示。
- 分离与重唱相关状态。
- 后续高级设置入口。

未实现或暂不适合当前版本交付的功能应置灰或折叠到设置中，避免误导用户。

## 6. 右侧改词界面：AI 智能改唱工作舱

用户在中间歌词区点击或双击一句歌词后，右侧栏切换为“AI 智能改唱工作舱”。

界面内容包括：

- 返回按钮：退出改词工作舱，回到默认右侧面板。
- 选中时间戳：显示当前选中歌词的时间。
- 原始歌词：展示当前选中的原句。
- 输入新歌词：用户输入要替换的新歌词。
- 改词唱模式：当前为“本机轻量改词唱（无需显卡）”，只读显示。
- 后端说明：提示这是本机试听音频，不是云端大模型真唱。
- 启动智能改唱并修补：生成试听并替换当前句子的人声音频片段。
- 取消修改：退出当前改词状态。
- 重置原词：恢复原始歌词/原始人声音轨。
- 已生成试听版本列表：可套用或删除已有改词版本。

当歌曲被删除或列表被清空时，右侧改词工作舱必须同步清空选中句、输入框、试听版本和改词音频状态。

## 7. 底部播放控制区

底部栏始终可见，用于播放和实时试听。

从左到右包含：

- 停止按钮。
- 播放/暂停按钮。
- 播放模式按钮。
- 人声音量滑条。
- 伴奏音量滑条。
- 主输出增益滑条。
- VST 宿主入口。
- 跑调程度 `(F0)` 滑条。

顶部播放进度条位于底部栏上半部分，两侧显示当前时间和总时长。

滑条统一视觉规则：

- 已拉过部分为白色。
- 未拉部分为深灰。
- 滑块为白色圆点。

跑调程度调节不再显示额外加载进度条，保持卡片高度稳定。后台处理状态可通过全局状态提示表达，不在该卡片中增加额外高度。

## 8. 弹窗与状态提示

当前主要弹窗包括：

- 状态提示弹窗：用于显示导入、播放、失败、完成等短消息。
- 歌词生成确认弹窗：当导入歌曲没有歌词时，询问是否生成歌词。
- 删除确认弹窗：删除选中歌曲或清空列表前必须出现。
- 改词唱弹窗/右侧工作舱：旧弹窗入口保留，主流程以右侧工作舱为准。
- 设置弹窗：收纳不常用功能和实验功能。

状态提示应使用中文。涉及不可逆操作时，必须明确说明会删除哪些数据，并要求用户确认。

## 9. 颜色与组件规范

主要颜色：

- 背景：近黑色 `#07080d`。
- 主面板：`#0b0c12`、`#10121b`。
- 次级面板：`#151722`。
- 边框：`#242635`、`#34384a`。
- 主强调色：粉色 `#e12a83`。
- 二级强调色：亮粉 `#ff55ad`。
- 主文字：近白 `#f8f5fb`。
- 次文字：灰蓝 `#9aa0ad`。

组件规范：

- 主要操作按钮使用粉色填充。
- 次级按钮使用深色背景和浅边框。
- 当前选中项使用粉色边框或粉色半透明背景。
- 功能卡片圆角保持克制，当前多为 7 到 14 像素。
- 不使用大面积渐变装饰，优先保证信息清晰和工作流效率。

## 10. 交互约束

为避免快速连续点击导致卡顿，多个高成本操作存在冷却节流，例如播放切换、歌曲切换、删除、清空、扫描等。

导入、分离、生成歌词、改词唱、跑调渲染等耗时任务应通过状态文本或进度条提示用户当前正在处理。对不会立刻完成的任务，要避免界面无响应。

真实删除磁盘文件、清空歌曲库等不可逆操作必须二次确认。

## 11. 后续 UI 优化方向

- 增加亮色主题，与当前深色主题并列。
- 搜索框接入真实过滤功能。
- 右侧 DSP 面板继续细化实时波形、F0 波动和电平显示。
- 改词唱工作舱在真实模型接入后增加模型启动/关闭状态、模型占用提示和失败恢复入口。
- 删除确认弹窗可显示更详细的待删除路径列表。
- 对小屏窗口进一步压缩底部栏控件间距，避免横向拥挤。
